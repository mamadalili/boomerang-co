Raya 70: a wall-mounted vanity set made by Boomerang

Raya 70 is a wall-mounted vanity set made by Boomerang. It combines a 72 cm long cabinet, Omega 60 mirror and Aster 70 washbasin for everyday bathroom use.

The set includes a 72 × 41 × 35 cm cabinet, Omega 60 mirror and washbasin in sanitary porcelain. Each component is specified for this model in the Boomerang catalogue.
