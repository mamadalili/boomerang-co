- فایل‌های فرم استعلام شامل‌اند؛ مخزن عمومی هیچ دادهٔ ثبت‌شدهٔ درخواست‌ها یا فایل پیکربندی محرمانه ندارد.
- این snapshot خروجی عمومی است؛ Master داخلی، گزارش‌های عملیاتی و ورودی‌های خام را شامل نمی‌شود.
